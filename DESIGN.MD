# Design System

## Design Philosophy

Build interfaces that feel calm, intentional, and premium.

Think:
- Apple Human Interface Guidelines
- Linear
- Stripe
- Notion

Avoid Dribbble-style effects, unnecessary gradients, floating glassmorphism, or decorative elements.

---

# Brand Personality

- Premium
- Minimal
- Trustworthy
- Professional
- Financial
- Ethiopian-first
- Fast
- Clean

Every element should have a purpose.

# Layout Rules

One primary action per screen.

Never stack multiple primary buttons.

Use generous whitespace.

Maximum content width.

Avoid nested cards.

Avoid unnecessary containers.

---

# UX Rules

Always show the important information first.

Reduce scrolling.

Primary action should always be visible.

Use descriptive labels.

Avoid long paragraphs.

Minimize cognitive load.

Every tap should feel obvious.

---

# Motion
